## 📌 Overview

This personal developer portfolio serves as the central hub for **Emmanuel Samuel's** frontend engineering work. It emphasizes clean typographic hierarchy, responsive layout dynamics, and intuitive navigation to highlight featured applications, core proficiencies, and direct contact options.

---

## ✨ Features

- ⚡ **Dynamic Presentation**: Clean hero presentation highlighting technical specializations in React and modern CSS.
- 📱 **Adaptive UI**: Seamless responsiveness across mobile devices, tablets, and desktop resolutions.
- 🔗 **Direct Social & Contact Links**: Integrated quick links to connect via email, GitHub, and professional networks.
- 🚀 **High-Speed Delivery**: Optimized with Vite for rapid load times and deployed continuously via Vercel.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sage-NBA/Main-Portforlio-site.git
   cd Main-Portforlio-site
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
